# Robot Framework Playground: The Internet

Portfolio automation framework using:

- Python 3
- Robot Framework
- Browser Library
- Playwright
- uv
- GitHub Actions

Target application:
https://the-internet.herokuapp.com/

## Repo Framework Structure

- docs/
  - architecture documentation

- resources/
  - page objects
  - reusable keywords
  - locators
  - shared variables

- tests/
  - smoke suites
  - regression suites

## Current Framework Features

- Browser Library integration
- Shared browser lifecycle keywords
- Configurable execution settings
- Initial smoke validation test
